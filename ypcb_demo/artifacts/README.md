Generated evidence belongs here and is ignored by Git. Each verification or
build creates a new run directory with logs, source hashes, tool versions,
commands, and a JSON report. A simulation or Yosys pass is not a placed/routed
bitstream or a physical YPCB result.

Small preserved receipts for the October 17 physical test live in
[`../docs/hardware/20261017/`](../docs/hardware/20261017/README.md), so the
